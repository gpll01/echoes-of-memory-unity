
# Echoes of Memory

Echoes of Memory è un'esperienza interattiva sviluppata in Unity 6 e C# basata sul concetto di presenza sonora invisibile.

## Tecnologie
- Unity 6
- C#
- Universal Render Pipeline (URP)
- TextMeshPro
- Audio 3D Spazializzato

## Funzionalità
- Audio spazializzato 3D
- Attenuazione e direzionalità del suono
- Sistema di progressione con ricordi collezionabili
- UI personalizzata
- Trigger Collider e interazioni ambientali
